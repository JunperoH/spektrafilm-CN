# Spektrafilm：FILM 与 PRINT 每项参数详解

适用对象：本仓库发布的 Windows GPU 中文版。本文按**该安装包实际包含的 GUI 定义和计算代码**整理；界面上的英文通常把下表的下划线换成空格。你可以按 `Ctrl+F` 搜索参数英文名。这份文档不会改动软件或预设。

## 先建立一张心智地图

`输入图像 → 相机曝光 → 胶片显影（FILM）→ 放大机曝光 → 相纸显影（PRINT）→ 扫描/导出`

- **FILM** 改的是负片本身：冲洗方式、老化、乳剂内散射、层间显影、颗粒，以及拍摄前的柔焦滤镜。
- **PRINT** 改的是负片投影到相纸之后：相纸显影、影调形状、相纸眩光、预闪和放大机柔焦。
- **主界面 MAIN** 的 `Film profile`、`Print profile`、`Camera compensation EV`、`Print exposure`、放大机 `C/M/Y filter shifts` 是决定基础效果的另一组参数，不在 FILM/PRINT 标签页内。先选胶片和相纸，再讨论下面的微调。
- `active` 或 `diffusion_filter_active` 是总开关。关掉时，下面的数值通常会被保留，但不参与计算。
- `0` 往往表示不施加偏移；`1.0` 往往表示“保持该胶片预设的倍率”。但**不同胶片自带不同基准值**，不应把所有数值机械地重置成 0 或 1。
- `EV` 是曝光档位，`+1 EV` 约为两倍曝光；`µm` 是微米；`RGB` 是三个模拟色层；`CC` 是暗房彩色滤镜刻度。某些控制是实验性模型，变化不一定等于真实暗房中可直接测量的变化。

### 先学会一套比较方法

固定一张照片、一个胶片和一个相纸，保存初始预设。每次只改**一项**，点预览，然后用该项旁边的重置按钮回到基准。先观察亮部、暗部、颜色、细节和颗粒这五件事；看不出差异就无需继续调该项。下表中“增大”的方向是模型中的主要趋势，最终观感仍受胶片、相纸与曝光共同影响。

## FILM ① Push / Pull：迫冲与减冲

把它理解为**改变负片的显影**，而不是给成品套一个对比度滤镜。正值迫冲通常让负片反差增加；负值减冲通常让反差更柔和。大幅调整后要回 MAIN 重新检查拍摄曝光和相纸曝光。

| 参数 | 含义与调节方向 |
| --- | --- |
| `active`（启用） | 关闭则整个迫冲/减冲模块不参与计算，但记住已填的数值。适合快速对照。 |
| `mode`（模式） | `standard` 用较稳定的整条密度曲线伽马模型；`experimental` 进一步模拟快/慢乳剂子层及显影液耗竭，后面三个高级控制仅在此模式有意义。 |
| `stops`（档数） | 正值为迫冲，负值为减冲，`0` 不改变原胶片显影。此社区版标准模式按每档约 `1.2×` 的曲线伽马变化，模型意义是更硬或更软的负片，不等同于拍摄曝光补偿。 |
| `gamma_factor_fast`（快层伽马） | 仅实验模式。控制低曝光阈值的快乳剂子层；偏离 `1.0` 会改变负片暗部附近的曲线形状。 |
| `gamma_factor_slow`（慢层伽马） | 仅实验模式。控制中层和慢层；偏离 `1.0` 主要改变较高曝光区域的密度响应。 |
| `developer_exhaustion`（显影液耗竭） | 仅实验模式。`0` 表示不模拟耗竭；增大后把子层响应混向“显影液不足”的曲线，改变高密度区域的肩部形状。 |

## FILM ② Development：黑白胶片显影时间

这一组**仅在选用有显影时间数据的黑白胶片时出现**，彩色胶片看不到是正常的。

| 参数 | 含义与调节方向 |
| --- | --- |
| `film_development_time`（显影时间，分钟） | `0` 使用胶片预设的默认显影时间；填入分钟数时，程序选择该胶片数据中最接近的一组显影曲线，并非对任意时间做无限精细的物理预测。 |

## FILM ③ Aging：过期胶片

这是**合理化的过期负片外观模型**，并非每款胶片实测的多年老化数据。宏观的 `age_years` 与 `storage` 先给出基础衰退，其余项目在基础上叠加微调；初学者先只试前两项。

| 参数 | 含义与调节方向 |
| --- | --- |
| `active` | 总开关。关闭时年龄与下列手动调整都不生效。 |
| `age_years`（过期年数） | 过期多久。增大会综合增加底雾、反差损失、染料衰退、颗粒粗化与感光度损失；`0` 为不过期。 |
| `storage`（保存条件） | `frozen` 冷冻最慢、`cold` 冷藏较慢、`room` 室温、`hot-humid` 湿热最快；同样年数下，条件越差老化越明显。 |
| `fog_rgb`（RGB 底雾） | 在自动老化之外，再给各色层添加基础密度。会出现带颜色的暗部偏色和灰雾；与普通白平衡不同。 |
| `gamma`（整体反差修正） | 叠加在老化反差变化上的倍率；`1.0` 不额外修正，低于 1 通常让负片曲线更平。 |
| `gamma_rgb`（RGB 曲线交叉） | 三个色层分别改变曲线斜率；彼此不等会产生暗部和亮部偏向不同颜色的“交叉色偏”，单靠放大机滤镜难以完全校正。 |
| `density_scale`（染料密度） | 叠加的最大染料密度倍率；低于 `1.0` 让染料更淡，色彩与反差趋弱。 |
| `grain_gain`（颗粒增益） | 叠加的颗粒面积倍率；高于 `1.0` 让过期颗粒更粗更明显。 |
| `speed_loss_ev`（感光度损失） | 额外损失的曝光档数。正值意味着胶片更不敏感，同样拍摄曝光下负片更薄；需要回 MAIN 增加相机曝光来补偿。 |

## FILM ④ Halation：乳剂散射和背反射光晕

这一组含两种容易混淆的现象：**scatter** 是光在乳剂内部向周围散开，主要影响细节和局部光扩散；**halation** 是光穿过乳剂后从背面反射回来，在亮部边缘形成光晕。先试前四项总量/范围；下面按 RGB 和微米细调的项目属于建模级参数。

| 参数 | 含义与调节方向 |
| --- | --- |
| `active` | 散射及背反射光晕的总开关。 |
| `scatter_amount`（散射量） | 乳剂内发生散射的光所占强度；`0` 无散射，`1.0` 是模型预设的完整散射强度。增大通常使微细节更柔。 |
| `scatter_spatial_scale`（散射范围） | 散射核心与远端尾部的共同尺寸倍率；增大使影响范围更宽。 |
| `halation_amount`（光晕量） | 各色层背反射光晕的共同强度倍率；增大使高光周围光晕更明显。 |
| `halation_spatial_scale`（光晕范围） | 背反射第一圈范围的倍率；增大使光晕扩展更远。 |
| `boost_ev`（高光增强上限） | 在负片受光阶段，为最亮部分额外增强的最大档数；`0` 不增强。它会改变驱动光晕的高光输入，过高容易显得夸张。 |
| `protect_ev`（保护范围） | 从中灰往上保留多少档不做上述增强；增大使增强只从更亮的区域开始。 |
| `boost_range`（增强过渡范围） | 控制高光增强从无到有的过渡分布，`0–1`；增大通常让增强覆盖更宽的亮部区间，减小更集中在极亮处。 |
| `scatter_core_um`（RGB 散射核心，微米） | 三个色层各自的短距离高斯散射宽度；增大某一通道会更多地柔化该通道的细节。 |
| `scatter_tail_um`（RGB 散射拖尾，微米） | 各通道低强度、长距离散射的衰减尺度；增大使微弱散射延伸更远。 |
| `scatter_tail_weight`（RGB 拖尾比例） | 把每个通道的散射能量从核心分配到长拖尾，界面按百分比填；增大让远处的低强度晕散更多。 |
| `halation_strength`（RGB 背反射强度） | 每个色层单独的背反射比例，按百分比；调整通道比例会改变光晕颜色。不要简单把三个通道设成一样。 |
| `halation_first_sigma_um`（第一圈范围，微米） | 第一轮背反射的高斯宽度；增大使基础光晕更宽。 |
| `halation_n_bounces`（反射次数） | 叠加多少轮背反射；增加可能让光晕出现更宽、弱的外层。 |
| `halation_bounce_decay`（逐轮衰减） | 每轮光晕相对上一轮的强度比例；越高，后续宽光晕越不容易消失。 |
| `halation_renormalize`（能量归一化） | 开启时把新增光晕能量归一化，较好维持中灰亮度；关闭时更偏加法叠光，也可能抬高暗部。 |

## FILM ⑤ Couplers：DIR 显影耦合剂

胶片的一个色层在显影时会抑制**自己或其他色层**的显影。界面的矩阵把这种层间作用画出来：对角线是同层，非对角线是跨层。它主要改变曲线、色彩分离和局部饱和感，绝不是普通的“饱和度”滑块。

| 参数 | 含义与调节方向 |
| --- | --- |
| `active` | DIR 耦合剂计算总开关；关闭可以观察该胶片少了层间抑制的结果。 |
| `amount`（总量） | 对整张抑制矩阵的共同倍率；`1.0` 保留各格原始强度，`0` 近似去掉这种作用。 |
| `inhibition_samelayer`（同层抑制） | 只放大或缩小矩阵对角线；主要影响各色层自身的显影伽马与反差。 |
| `inhibition_interlayer`（层间抑制） | 只放大或缩小非对角线；主要影响色层相互作用和色彩分离。 |
| `gamma_samelayer_rgb`（R/G/B 同层伽马） | 对角线三格：每层对自身的抑制强度。分别改动会改变不同色层的曲线形状。 |
| `gamma_interlayer_r_to_gb`（R→G/B） | R 层对 G、B 层的两项抑制强度。 |
| `gamma_interlayer_g_to_rb`（G→R/B） | G 层对 R、B 层的两项抑制强度。 |
| `gamma_interlayer_b_to_rg`（B→R/G） | B 层对 R、G 层的两项抑制强度。 |
| `diffusion_size_um`（扩散范围，微米） | 耦合剂在乳剂内向邻近位置扩散的空间宽度；增大使作用更宽，也可能影响局部锐度和饱和表现。 |

界面中上述四组 `gamma_*` 可能合并成一张 3×3 滑块矩阵；这是同一批参数，并非额外的九个独立功能。

## FILM ⑥ Grain：负片颗粒

颗粒在**负片阶段**生成，再经过后续冲印和扫描，所以它不等于最后叠上的一层随机噪点。`model` 决定当前采用哪套颗粒算法；软件会隐藏不属于该算法的控制。尤其注意：`preview` **是颗粒模型的名字**，选择它后导出也会按这个模型计算，不只是让界面预览变快。

| 参数 | 含义与调节方向 |
| --- | --- |
| `active`（启用） | 负片颗粒总开关。关掉能直接比较“颗粒对画面”的贡献。 |
| `model`（模型） | `production` 是较完整的分层染料云颗粒，适合作为成品基准；`preview` 是更快、匹配噪声幅度的近似；`rms` 按胶片资料中的 RMS 颗粒度校准；`synthesis` 是计算开销很大的蒙特卡洛研究模型。 |
| `sublayers_active`（启用子层） | 让颗粒按每个色层内的不同乳剂子层生成；关闭会简化这种分层结构。仅有关联模型显示此项。 |
| `particle_area_um2`（颗粒面积，µm²） | 基础颗粒截面积；增大通常使颗粒更粗。它与下面的通道和子层倍率相乘。 |
| `particle_scale`（RGB 颗粒倍率） | R/G/B 色层各自的面积倍率；某通道越大，该层颗粒特征越粗。 |
| `particle_scale_layers`（子层面积倍率） | 快、中、慢三个乳剂子层各自的颗粒面积倍率，用于做出层次不同的颗粒。 |
| `density_min`（最低密度） | 各色层颗粒模型的密度基底/下限；会参与负片光密度计算，不应只当成视觉“黑色值”。 |
| `uniformity`（均匀度） | 控制随机颗粒分布的均匀程度；越接近 `1` 越均匀，降低时局部起伏通常更明显。 |
| `blur`（颗粒模糊） | 以像素为单位对颗粒做高斯平滑；增大让颗粒边缘更柔，在高放大倍率下尤其明显。 |
| `blur_dye_clouds_um`（染料云模糊，µm） | 染料云自身的物理尺度模糊；主要在高放大率下看出差别。 |
| `micro_structure`（微观结构，两值） | 第一值控制微观聚团的模糊尺度，第二值是分子团尺寸（nm）；主要用于非常极端的放大观察。 |
| `rms_granularity`（RMS 颗粒度，RGB） | **仅 RMS 模型**。按胶片数据表的测量定义输入各通道目标颗粒度：在特定密度与 48 µm 测量孔径下的密度标准差 ×1000。不是普通百分比。 |
| `rms_strength`（RMS 强度） | **仅 RMS 模型**。`1.0` 使用上面的目标值；增大让目标颗粒更显眼，减小更干净。 |
| `synthesis_size`（合成尺寸） | **仅 synthesis 模型**。平均颗粒半径的倍率，增大使颗粒实体更大。 |
| `synthesis_amount`（合成混合量） | **仅 synthesis 模型**。把合成颗粒密度混入干净负片的比例；`1.0` 为完整效果。 |
| `synthesis_sharpness`（合成锐度） | **仅 synthesis 模型**。缩小观察孔径，使单颗粒更清楚；增大更锐、更显颗粒。 |
| `synthesis_quality`（合成质量） | **仅 synthesis 模型**。增加蒙特卡洛采样量；增大结果更稳定，但渲染更慢。 |

### Grain synthesis：仅选择 `synthesis` 后出现的研究级控制

| 参数 | 含义与调节方向 |
| --- | --- |
| `synthesis_samples`（采样数） | 每像素基础蒙特卡洛采样次数；越高越慢，随机估计更平稳。 |
| `synthesis_mean_radius_um`（平均半径，µm） | 在胶片平面上模拟的银粒平均半径；增大生成更大的颗粒。 |
| `synthesis_radius_stddev_ratio`（半径离散度） | 颗粒半径分布的相对离散程度；增大让颗粒大小差异更大。 |
| `synthesis_aperture_sigma_um`（观察孔径，µm） | 观察/采样孔径的高斯宽度；`0` 使用由像素尺寸确定的自动值，增大通常使颗粒被平均得更柔。 |
| `synthesis_cell_size_ratio`（采样单元尺寸比） | 空间采样单元相对于平均颗粒半径的大小；影响内部采样划分与计算开销，通常保持默认。 |
| `synthesis_max_radius_quantile`（最大半径分位点） | 把极端大的颗粒半径截在指定分布分位点，防止罕见巨粒主导结果；降低时截断更严格。 |
| `synthesis_coverage_epsilon`（覆盖率下限） | 给“未被颗粒覆盖的比例”设置数值下限，限制最大合成密度；增大时上限压得更低。 |
| `synthesis_max_grains_per_cell`（每单元最大颗粒数） | 限制每个采样单元实际创建的颗粒数量；调高可减少上限截断，但增加计算成本。 |
| `synthesis_radius_scale`（RGB 半径倍率） | 每个色层颗粒半径的单独倍率；`1.0` 保持共同基准。 |
| `synthesis_layered`（分层） | 把合成颗粒场分为三层深度结构；纹理更复杂，但该模型说明约增加到三倍的渲染成本。 |
| `synthesis_layer_scale`（深度层倍率） | 开启分层后，三层各自的平均半径倍率。 |

## FILM ⑦ Bleach bypass：负片跳漂白

真实冲洗中漂白本会去掉银；“跳漂白”让部分银留在染料旁边。这里是**有物理依据的扩展模型**，并非每款胶片的实测跳漂白数据。加大后应重新检查相纸曝光。

| 参数 | 含义与调节方向 |
| --- | --- |
| `negative_bleach_bypass`（负片跳漂白） | `0` 关闭；增大使负片保留更多与显影量相关的中性银密度，通常带来更硬、更沉的观感，并改变通过放大机的光量。 |
| `negative_leuco_cyan_coupling`（无色青染料耦合） | 研究级倍率：模拟跳漂白时一部分青染料没有形成。`1.0` 是模型预设；只在负片跳漂白不为零时有意义。 |

## FILM ⑧ Camera diffusion：相机前柔焦滤镜

滤镜作用在**胶片曝光之前**，因而与 PRINT 页放大机柔焦的作用阶段不同。该组把柔焦分成紧邻亮点的 `core`、周围的 `halo`、更远的 `bloom`。调“强度”改变被偏转的总体光量；调三层 `intensity` 是重新分配光量，三层权重最后会重新归一化，并不等于简单把总柔焦强度加大。

| 参数 | 含义与调节方向 |
| --- | --- |
| `camera_diffusion_filter_active` | 总开关；关闭时下面参数不产生相机柔焦。 |
| `camera_diffusion_filter_family`（滤镜系列） | 选择 `glimmerglass`、`black_pro_mist`、`pro_mist`、`cinebloom` 等不同的光晕核形状与吸收特征；换系列后相同强度也可能有不同观感。 |
| `camera_diffusion_filter_strength`（滤镜强度） | 近似商业滤镜档位：`0`、`1/8`、`1/4`、`1/2`、`1`、`2`；增大一般使柔焦更明显。 |
| `camera_diffusion_filter_spatial_scale`（空间倍率） | 把 `core/halo/bloom` 的所有空间尺寸一起放大或缩小；增大使柔焦扩散更远。 |
| `camera_diffusion_filter_halo_warmth`（光晕暖调） | `0` 使用该系列默认色调；正值让外层光晕偏暖、内层偏冷，负值反过来。 |
| `camera_diffusion_filter_core_intensity`（核心权重） | `1.0` 使用系列默认；调高让更多散射光落在贴近亮点的核心，同时相对减少其他层的份额。 |
| `camera_diffusion_filter_core_size`（核心尺寸） | `1.0` 默认；调高让紧邻亮点的核心更宽。 |
| `camera_diffusion_filter_halo_intensity`（中圈权重） | 调高中圈光晕在总散射中的占比；`1.0` 是系列默认。 |
| `camera_diffusion_filter_halo_size`（中圈尺寸） | 调高中圈扩展半径；`1.0` 是系列默认。 |
| `camera_diffusion_filter_bloom_intensity`（远端泛光权重） | 调高最宽的泛光层所占份额；`1.0` 是系列默认。 |
| `camera_diffusion_filter_bloom_size`（远端泛光尺寸） | 调高最宽泛光层的扩展半径；`1.0` 是系列默认。 |

## PRINT ① Chemistry：相纸显影化学

这里修改的是**相纸自身的密度响应曲线**，不是修改负片。总开关关闭时使用纸张原本的显影曲线；MAIN/TUNE 中的其他相纸伽马控制可能仍独立有效。调整纸张曲线可能同时改变反差、颜色和亮度，切勿把它当成只影响“鲜艳度”的开关。

| 参数 | 含义与调节方向 |
| --- | --- |
| `active`（启用） | 相纸显影曲线形变总开关；关闭可比较纸张原始曲线与调整后曲线。 |
| `gamma_factor`（整体伽马） | 对所有纸张色层共同改变曲线斜率；高于 `1.0` 一般使响应更陡、反差更硬，低于 `1.0` 更柔。实际亮暗也会改变。 |
| `gamma_factor_fast`（快层伽马） | 针对相纸最快感光子层的额外曲线倍率；主要影响纸张响应的一部分影调区域，`1.0` 不额外调整。 |
| `gamma_factor_slow`（慢层伽马） | 针对中层、慢层的额外曲线倍率；与快层共同决定整体曲线形状，`1.0` 不额外调整。 |
| `gamma_factor_red`（R 通道伽马） | 只改一个通道的纸张密度曲线斜率；会让该通道的颜色随明暗发生不同变化。 |
| `gamma_factor_green`（G 通道伽马） | 同上，作用于 G 通道。 |
| `gamma_factor_blue`（B 通道伽马） | 同上，作用于 B 通道。界面可能把三项并排画成 `Gamma RGB` 旋钮。 |
| `developer_exhaustion`（显影液耗竭） | 让纸张子层曲线逐渐混向显影液耗竭时的肩部形状，同时保持中灰参考；`0` 不模拟耗竭。主要用于研究高密度端的渐变。 |

## PRINT ② Paper shaping：相纸影调塑形

这三项在相纸显影后、扫描前起作用；前两项保持相纸最小/最大密度端点不动，改变中间影调如何接近黑白两端。它们不是把整张图简单提亮或压暗。

| 参数 | 含义与调节方向 |
| --- | --- |
| `print_shadow_shape`（暗部形状） | 正值打开成品暗部，让深灰更易区分，但保留最深黑；负值让暗部更沉。`0` 不塑形。 |
| `print_highlight_shape`（亮部形状） | 负值使高光过渡更柔和，正值使亮部更硬、更快接近纸白；`0` 不塑形。 |
| `print_bleach_bypass`（相纸跳漂白） | 模拟**相纸/印片材料**显影后留下一部分银，与 FILM 页的负片跳漂白发生在不同阶段。增大会增加中性银密度并改变成品反差与颜色；`0` 关闭。它同样是扩展模型，不是特定纸张的实测参数。 |

## PRINT ③ Glare：观察/扫描相纸时的眩光

程序在扫描相纸反射光时加入一层偏白的杂散光。因此它更像**观看或扫描成品时的眩光**，不是相机镜头光晕；通常会使深色区域抬起、画面对比下降。

| 参数 | 含义与调节方向 |
| --- | --- |
| `active`（启用） | 相纸眩光总开关。 |
| `percent`（眩光比例） | 加入的杂散光平均比例；增大通常会让黑位更浅、整体更泛白。代码以百分比处理此值。 |
| `roughness`（粗糙度） | 控制杂散光在空间上随机起伏的程度；增大让眩光分布更不均匀。 |
| `blur`（模糊） | 以像素为单位平滑上述随机眩光；增大使块状/起伏更宽、更柔。 |

## PRINT ④ Preflash：相纸预闪

在正式把负片投影到相纸之前，给相纸一层非常轻的、可加滤色片的均匀预曝光。它主要作用于**接近纸白的亮部**，可让原本过白的层次变得可见；太强则会使白色发灰。注意它不是给数字图像整体加亮。

| 参数 | 含义与调节方向 |
| --- | --- |
| `active`（启用） | 预闪总开关；关闭后按零预闪计算，下面数值仍保留。 |
| `exposure`（预闪曝光） | 预闪光量；`0` 等于没有预闪，增大会让纸张在正式曝光前先受更多光。**这版界面的悬浮提示写“EV”，但计算代码把输入值直接作为线性曝光系数使用，并没有做 `2^EV` 换算。**因此不要按“+1 就翻倍”的 EV 规则理解它。 |
| `y_filter_shift`（预闪 Y 滤镜偏移） | 只改变**预闪光**的黄色滤镜，相对中性位置偏移，单位 Kodak CC；区别于 MAIN 放大机正式曝光的 Y 滤镜。 |
| `m_filter_shift`（预闪 M 滤镜偏移） | 同上，但调整洋红滤镜。 |
| `c_filter_shift`（预闪 C 滤镜偏移） | 同上，但调整青色滤镜；传统暗房中常保持 `0`。界面上三项可能合并为 `Filter shifts` 的 C/M/Y 旋钮。 |

## PRINT ⑤ Diffusion：放大机/相纸阶段柔焦

与 FILM 页相机前柔焦的控制逻辑相同，但**发生在负片形成之后**。因此换位置会改变光晕如何与负片颗粒、光晕和相纸曲线相互作用；不应该把同样的数值同时复制到两个位置。

| 参数 | 含义与调节方向 |
| --- | --- |
| `diffusion_filter_active` | 放大机/相纸阶段柔焦总开关。 |
| `diffusion_filter_family`（滤镜系列） | 选择 `glimmerglass`、`black_pro_mist`、`pro_mist`、`cinebloom` 等光学扩散形状；不同系列的散射和吸收行为不同。 |
| `diffusion_filter_strength`（强度） | 近似商业柔焦滤镜的 `0`、`1/8`、`1/4`、`1/2`、`1`、`2` 档；增大时总柔焦更明显。 |
| `diffusion_filter_spatial_scale`（空间倍率） | 同时缩放核心、中圈和远端泛光的范围；增大使柔焦影响更宽。 |
| `diffusion_filter_halo_warmth`（光晕暖调） | `0` 用系列默认；正值外暖内冷，负值外冷内暖。 |
| `diffusion_filter_core_intensity`（核心权重） | 调高让更多散射光分给紧邻亮点的核心；`1.0` 为该系列默认。三层权重会重新归一化。 |
| `diffusion_filter_core_size`（核心尺寸） | 调高使核心更宽；`1.0` 为系列默认。 |
| `diffusion_filter_halo_intensity`（中圈权重） | 调高中圈光晕的相对份额；`1.0` 为系列默认。 |
| `diffusion_filter_halo_size`（中圈尺寸） | 调高中圈扩散半径；`1.0` 为系列默认。 |
| `diffusion_filter_bloom_intensity`（远端泛光权重） | 调高最宽的泛光层所占份额；`1.0` 为系列默认。 |
| `diffusion_filter_bloom_size`（远端泛光尺寸） | 调高远端泛光范围；`1.0` 为系列默认。 |

## 实际学习顺序

1. **先学 MAIN**：用同一张图固定 `Film profile` 和 `Print profile`，确认相机曝光与相纸曝光的区别。
2. **FILM 先学三组**：`Push / Pull → Halation → Grain`。每组先只改总开关或第一层“大旋钮”，不要一开始进入 RGB 矩阵和微米参数。
3. **PRINT 先学三组**：`Paper shaping → Preflash → Glare`。用同时含有明亮白色和深色阴影的图，更容易看到它们的作用位置。
4. **最后学研究级控制**：`Aging`、`Couplers`、`Chemistry`、`Grain synthesis` 与两处 `Diffusion` 的内部权重。此时始终与初始预设做 A/B 对照。

### 什么情况下参数看起来“没反应”

- 模块 `active` 为关闭；某个颗粒模型的专属项目不适用于当前模型。
- 选了正片或开启 `Scan film`，软件会跳过 PRINT 阶段，并隐藏相关组；这时怎么调相纸参数都不会改变当前胶片扫描画面。
- `Development` 只用于带显影时间曲线的黑白胶片。
- 图像尺寸小或预览缩小得厉害时，微米级颗粒/柔焦差异可能看不出来；用局部放大或完整渲染比较。
- 某些差异被自动曝光、相纸自动补偿或后续扫描设置部分抵消；先只比较一个模块，必要时固定自动调节。
