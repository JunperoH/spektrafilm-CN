# Spektrafilm 参数入门（Windows GUI）

这份说明适用于本仓库提供的 `Spektrafilm.exe`。下文把常见英文标签一并写出，方便对照原始术语。它模拟的是「数字图像 → 胶片负片 → 放大机 → 相纸或电影正片 → 扫描」的过程。界面中的“相纸”是模拟对象，不要求你真的打印照片。

## 先用这一组设置

1. 导入一张照片。RAW 可走 **Import RAW**；普通 TIFF/PNG/JPEG 可走 **Import RGB**。
2. 在 **Film profile / 胶片型号** 选 `kodak_portra_400`，在 **Print profile / 相纸型号** 选 `kodak_supra_endura`。这是一个入门组合，目的是先熟悉控制方向，不是唯一正确的风格。
3. 保持 **Auto exposure / 自动曝光** 开启、**Exposure compensation EV / 曝光补偿** 为 `0`、**Print auto compensation / 相纸自动补偿** 开启、**Print exposure / 相纸曝光** 为 `1.0`、**Y/M filter shift / 黄色与洋红滤镜偏移** 为 `0`。其他参数先保留默认。
4. 点 **Preview / 预览**。一次只改一个参数，再预览并比较。满意后用 **Scan / 完整渲染** 或社区版的 **Export / 导出** 输出。

## 必须先懂的 6 项

| 界面名称 | 它实际控制什么 | 初学者怎么用 |
| --- | --- | --- |
| Film profile（胶片型号） | 模拟哪一种拍摄胶片的感光和密度曲线；这是画面性格的主要来源。 | 先选一种，比较时只换这一项。`Portra`、`Gold`、`Vision3` 是不同胶片系列。 |
| Print profile（相纸型号） | 模拟负片最终印到哪一种材料上，影响反差与颜色。 | 先用 `Kodak Supra Endura`。`Endura`、`Crystal Archive` 是摄影相纸；`2383/2393` 是电影拷贝胶片，属于不同输出风格。 |
| Auto exposure / Exposure compensation EV（自动曝光／曝光补偿） | 调整进入虚拟拍摄胶片的曝光量。`+1 EV` 代表多一档曝光。 | 自动曝光先开着，EV 从 `0` 开始；这会改变负片的形成，不只是把成品整体提亮。 |
| Print auto compensation（相纸自动补偿） | 改动拍摄曝光时，自动联动相纸曝光以维持可用的成品亮度。 | 起步保持开启，便于单独观察胶片曝光对影调的影响。 |
| Print exposure（相纸曝光） | 虚拟放大机给相纸的曝光量。它与拍摄曝光处在不同阶段。 | 从 `1.0` 开始。通常调大使成品更暗，调小使成品更亮；每次小幅调整后看预览。 |
| Y / M filter shift（黄色／洋红滤镜偏移） | 在放大机上微调冲印光色，主要用于纠正成品偏色。 | 两项先保持 `0`；`0` 是该胶片与相纸组合的中性基准，**不是完全没有滤镜**。有明显偏色时一次只调一项，并观察方向。 |

## 下拉列表太长时，先认这几类

| 名称示例 | 先把它理解成 |
| --- | --- |
| `Kodak Gold 200`、`Kodak Portra 400` | 普通彩色负片；最适合拿来学习“负片 → 相纸”流程。 |
| `Kodak Vision3 250D`、`500T` | 电影摄影负片；`D` 是日光型，`T` 是钨丝灯型。 |
| `Ektachrome`、`Velvia`、`Provia` | 彩色正片。它们通常直接看胶片扫描效果，所选“相纸”可能不会像负片流程那样发挥作用。 |
| `Kodak Supra Endura`、`Fuji Crystal Archive` | 摄影相纸。先固定一款，再比较胶片，最容易看懂差异。 |
| `Kodak 2383`、`2393` | 电影拷贝胶片，不是通常意义上的摄影相纸；先熟悉摄影相纸后再试。 |

## FILM（胶片）和 PRINT（相纸）页怎么理解

- **FILM → Grain（颗粒）**：模拟胶片颗粒。先用默认；觉得颗粒抢眼时先降低强度或暂时关闭，而不是同时改很多颗粒子参数。
- **FILM → Halation（光晕）**：亮部边缘的光晕。先看默认效果，确认真的需要更明显时再调强度。
- **FILM → Couplers（耦合剂）**：胶片层间的显影相互作用，会影响色彩和对比。属于高级参数，起步不动。
- **FILM → Camera diffusion（相机柔焦滤镜）**：模拟镜头前柔焦滤镜。需要柔和高光时再开启。
- **PRINT → Chemistry（显影化学）**：修改相纸显影曲线和颜色表现。起步不动。
- **PRINT → Glare（眩光）**：模拟光学散射造成的反差变化。起步不动。
- **PRINT → Preflash（预闪光）**：模拟正式曝光前给相纸少量预曝光。起步不动。
- **PRINT → Enlarger diffusion（放大机柔焦滤镜）**：模拟冲印环节的柔焦，与相机前滤镜作用阶段不同。起步不动。

## 三个容易误会的地方

1. **胶片与相纸不是一对固定套餐。**可以自由组合，但换一个胶片或相纸后要重新检查曝光与色彩。
2. **`Scan film` / 扫描胶片不是最终成品的“扫描质量”开关。**它是查看胶片本身，而不是看相纸成品。使用 `Ektachrome`、`Velvia` 等正片时尤其相关。
3. **预览、完整渲染、导出不是三个不同的滤镜。**预览用于快速试参数；完整渲染或导出用于最终尺寸。社区版可能单独提供导出面板。

## 最省事的调参顺序

先固定相纸，逐个比较 2–3 种胶片；选定胶片后，再比较 1–2 种相纸。接着只调相纸曝光，解决最终亮暗；最后才调整颗粒、光晕与柔焦。每次找到喜欢的结果就保存为预设，避免下次从头开始。
