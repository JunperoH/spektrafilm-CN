# Spektrafilm GPU 中文版

双击 `Spektrafilm.exe` 启动。界面分为主界面、胶片、相纸、扫描、高级和设置六页。鼠标停在参数名称上，可以看到中文说明。更完整的解释见同目录的 `FILM-PRINT-参数详解.md`。

## GPU 开关

界面底部的“GPU 加速（Vulkan）”默认勾选。开启后，下次点击“预览”或“扫描”时使用 GPU 光谱计算；关闭后切回 CPU。状态文字会显示当前后端。是否能启用 GPU 取决于你的显卡和 Vulkan 驱动。

## 第一次尝试

1. 在“主界面”导入 RGB 或 RAW 图像。
2. 选择胶片型号和相纸型号，先保留其他默认值。
3. 点击“预览”看整体效果，需要完整分辨率时点击“扫描”。
4. 从相机曝光补偿、放大机曝光和滤镜偏移开始学习。胶片/相纸页的高级参数先保持默认。

界面翻译只改变显示文字，不改变配置文件中的参数键、枚举值和胶片配置名称。
